# Deutsch Nomen Trainer

Локальный Vue 3 + Vite тренажёр для распределения немецких существительных по родам.

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Откройте URL, который покажет Vite (обычно http://localhost:5173). Для проверки production-сборки: `npm run build`.

## Формат TXT
Каждый блок начинается с отдельной строки списка в квадратных скобках:
```text
[der Mann, die Frau, das Kind]
Правильный ответ:
М.Р: Mann
Ж.Р: Frau
Ср.Р: Kind
Перевод слов:
Mann - Мужчина
Frau - Женщина
Kind - Ребёнок
```
Разделяйте существительные запятыми. Между блоками можно оставлять пустую строку. Допускаются пустые строки после меток рода, если в этом блоке нет слов этого рода. Для каждого слова нужен ответ и перевод. Строки, начинающиеся с `#`, игнорируются.

## Возможности
- TXT upload; файл читается локально в браузере.
- Построчные ошибки формата с номерами строк и диагностикой незаполненных ответов/переводов.
- Автоматическое снятие определителей/артиклей со списка слов (включая падежные формы и распространённые притяжательные/указательные формы).
- Выбор существительного, показ перевода, распределение в `der` / `die` / `das`.
- Проверка с зелёной/красной подсветкой, счётчиком правильных ответов и повторной попыткой.

## Ограничения формата
Список в квадратных скобках — обязательный источник слов для упражнения. Правильный ответ должен содержать те же существительные без артиклей. Перевод указывается в формате `слово - перевод`. Для составных выражений с несколькими словами используйте одну запись на элемент списка; запятые внутри перевода не поддерживаются как разделители слов.
